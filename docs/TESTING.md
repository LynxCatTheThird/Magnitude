# 构建与测试

需要 Java 25。设置 `JAVA_HOME` 指向自己的 JDK，使用仓库提供的 Gradle wrapper。第一次构建需要网络下载固定的 Minecraft/Fabric/Loom 依赖；已有缓存时可以加 `--offline`。

```bash
./gradlew --no-daemon check build
```

`check` 包含纯规则 `ruleTest` 与 `runVerificationServer`。测试源码和测试模组元数据随仓库提交；测试类与验证入口不会打包进生产 JAR。生产 JAR 位于 `build/libs/`。

验证服务端只监听 `127.0.0.1`，使用系统分配的临时端口、离线测试身份和 `.local/verification/` 下的专用测试世界；不需要用户账户。任务为测试服务端准备 EULA 和配置文件。测试只修改该测试世界，夹具每轮清理固定区域，等待确定的 tick 后执行；正常和异常路径都会停止测试服务端。任务最长运行 2 分钟。

结果写入 `.local/verification/results.json`。任务删除旧结果后启动；无结果或 `success=false` 时 Gradle 必须失败，不能以 Minecraft 进程自身的正常退出码替代测试结果。失败的断言名称会进入 Gradle 错误。

纯规则包含 300012 条断言，大部分是固定随机种子的尺寸转移性质验证。真实服务端用例覆盖尺寸边界/渐变/NBT、注册、许可、携带、抛出、原版玩家载体 guard、断连/卸载、真实死亡/维度传送、重生状态、药水效果来源、红石、流体、保护 veto、请求洪泛拒绝及密集候选查询配额；断连与重生部分使用事件回调，身份与连接对象在本地构造，没有第二个真人客户端。0.1.2 另包含微型 2⁻²⁰/巨型 2³² 的真实实体尺寸、渐变与存档、物理代理、普通移动包触发跳跃、左右脚印/朝向、静止硬度压力、浮点存量和 1000 次巨型地形请求无新增碎屑实体的验证。压力夹具使用有限石头区域，不能代替大型世界的 FPS/MSPT、自然沙砾更新链与第三方物理模组测试。

0.1.3.1 新增真实实体的脚部落地、固体墙、玻璃板扫掠、半砖台阶、骨骼空隙、普通移动包位置校验、真实交替单脚起跳、支撑/适配器校验、动态代理增长与收缩、未加载区域不强制加载、空区域遍历限额、候选配额耗尽的保守移动、微型落地、关节姿态穿透拒绝及姿态协议往返。该版本共 197 项服务端断言。客户端完成入口、渲染 Mixin 和资源加载检查；新增 BASE 派生的跳跃/攻击倍率与缓存立即刷新回归；没有完成真实双客户端、动画包或长期性能验收。

确认失败传播可以执行以下诊断命令；预期退出码非零：

```bash
./gradlew --no-daemon runVerificationServer -PverificationFailure=true
```

它在正常用例完成后故意抛出断言错误。之后重新运行普通 `check` 获得有效成功结果。

客户端开发启动：

```bash
./gradlew --no-daemon runClient
```

客户端需要可用显示环境。启动检查覆盖入口、Mixin 和资源加载，不覆盖世界中的全部交互。进一步人工验收应包含：两客户端 opt-in/撤回、携带偏移同步与安全释放、喷溅/滞留/箭投递、巨型/微型第一和第三人称视角、GUI、观察/精度按键、世界边界、具体领地模组以及混合场景长期负载。

## 碰撞分配性能回归

`check` 同时执行 `CollisionPerformanceTests`：以优化前的 SAT 算法为参照，验证 10000 个固定随机种子的旋转盒及其平移后的重叠与扫掠结果一致。预热后使用 JVM 线程分配计数器对照 10000 组扫掠和重叠查询，要求优化后的分配量至少减少 75%。测试参照与测量代码只进入验证模组，不打包进发布 JAR。

本地两次测量：查询临时分配由约 15.8～20.6 MB 降至 0；旧算法耗时约 6～15 ms，优化后约 4～5 ms，受预热/JIT 和机器负载影响。该测量不包含身体部位创建、世界遍历、方块更新和客户端渲染，不能推算整个游戏的 FPS 或 MSPT。耗时只记录，不作为受机器负载影响的通过门槛。普通尺寸玩家跳过无用的代理扩张，巨型代理扩张最多每 5 ticks 探测一次；未加载边界收缩和移动前的范围校验仍执行。

## 0.1.4-alpha1 尺寸快照与接触回归

`check` 包含尺寸快照、接触事件和权限测试。快照用例覆盖极端尺寸、连续尺寸样本、同 tick 写入、渐变、姿态及代理变化；接触用例覆盖事件去重、支撑变化、压力许可、落地、障碍作用后的碰撞重查询、预算耗尽与未加载区域。协议用例拒绝重复或过时的姿态版本，权限用例检查全局物理命令的管理员边界。

## 0.1.4-alpha2 玩法回归

`GameplayPhysicsTests` 覆盖 4.5/5/5.5 倍跨两格平台、普通尺寸的跨越限制、原中心探针漏检的树干、扫掠外方块保留、材料硬度、容器、软地面低倍率脚印、静止脚掌支撑与查询预算耗尽。另覆盖49.5/50倍真实腿间路灯、运动缩放后的跳跃限速、50倍接触破坏、超过旧半径的分批脚印、落地深度、写入时容器重验与许可撤回。自动步高随BASE连续变化，实际结果仍受方块离散几何影响。

打包验证应移除松散的运行时依赖和主源码输出后，通过生产 JAR 的嵌套依赖启动；再验证重复兼容副本只加载一个运行时，不兼容外部版本回退到内置兼容运行时，移除内置副本后仅有不兼容运行时导致解析失败。开发环境松散依赖启动不能替代这项检查。

Accessible Step 2.4.1+26.3 与当前客户端共同启动到资源图集加载；服务端夹具将原版步高属性设为零，仍验证连续跨两格平台。尚未完成用户世界共存操作与长期性能验收。

## 0.1.4-alpha3 实测问题回归

真实服务端夹具覆盖5、17.25、50倍的100格行走落脚次数、移动时不重复静压、同侧脚印间保留地面、短暂下落中多层树干/密集树冠的连续接触、房屋墙体与屋顶分批清除后通行，以及无阻挡碰撞的蜘蛛网接触。脚印按定向矩形与方块重叠生成。碰撞仍须完整查询后才允许移动；部分接触的破坏可逐刻继续。用户提供的自然村庄和原世界尚需新包复验。

## 0.1.4-alpha4 站立稳定性

50倍实体执行100次真实重力移动、接触采样和队列推进，验证高度保持、位于方块边缘的双脚实际支撑保留及下一层不被破坏；另验证自身导致的下落不能重触发落地挖掘或同位置更深静压。主动跳跃后的落地破坏仍运行原有回归。

## 0.1.4-alpha5 支撑与查询诊断

强制耗尽碰撞预算后切换巨型支撑脚，验证回退保留旧着地腿且落脚事件可破坏地面；验证只转头时仅查询变化的头部，运动计时样本有界。截图中的高FPS与原版行走粒子不能证明服务器接触事件正常，需结合status中的刻耗时、查询耗时和拒绝比例。没有以本轮优化声称自然世界卡顿已解决。

## 0.1.4-alpha6 脚印—移动闭环

`FootprintCycleTests`耦合真实Entity.move、运动倍率、重力、服务端姿态/接触和队列写入：5/17.25/50倍各120次移动，平地前进60格，高度保持200、台阶抬升0、移动拒绝0。另验证整片承重地面不挖掘、卸载后脚印中心及周边统一一格深且下一层保留。该夹具证实这一场景的行为，不能证明自然村庄FPS/MSPT已恢复。

旧材料/保护用例现在通过测试专用`FootprintRelease`明确抬离接触面，再断言写入；该辅助类不进入生产包。站立和连续运动回归继续调用生产队列，不使用模拟抬脚。

## 0.1.4-alpha7 配置与GUI验证

`ConfigTests`加入共享配置服务的权限检查、批量输入校验、过期版本、实际文件写入失败、备份、旧命令委托、错误重载，以及设置请求/回执编码边界。真实服务端总断言363项；规则断言仍300012项。

独立客户端验证入口`GuiTests`由`-Dmagnitude.guiVerification=true`启用，只在验证模组中存在。它在实际客户端检查离线页面、编辑保存、非管理员只读控件、分页、320×240缩放布局、非法数字与关闭草稿，并输出截图和gui-results.json；验证时使用隔离运行目录，不能加载用户存档。

`GuiNetworkTests`由`-Dmagnitude.guiNetworkVerification=true`启用，连接`-Dmagnitude.testServer=127.0.0.1:<port>`。分别使用普通玩家和管理员（后者设置`-Dmagnitude.guiAdmin=true`）验证真实GUI请求/确认、权限伪造拒绝、命令/GUI一致性和过期编辑。专服隔离目录设置offline模式及本地监听，并为测试管理员配置ops.json。该运行需禁用自动专服夹具（设置`-Dmagnitude.guiVerification=true`）；结果写入network-results.json。

这些检查不证明复杂模组包中的全部菜单布局兼容或长期FPS/MSPT。生产JAR应排除全部验证入口和类。

## 0.1.4-alpha8 唯一CLI
