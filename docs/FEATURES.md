# 功能覆盖与设计边界

本文区分已实现、由底座/原版提供、主动重设计和未实现；注册物品并不表示参考玩法已完整迁移。

| 功能                                                | 状态                   | 当前实现与边界                                                                                                                            |
| --------------------------------------------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 模型、碰撞、眼高、移动等基础缩放                    | 由 Rebuilt/原版提供    | Magnitude 只写 BASE，不另乘模型或原版 scale 属性；默认范围 1/64..32，配置可扩大到 2⁻²⁰..2³²；独立限制碰撞/运动/交互，极端客户端观感待验收 |
| 自身/管理员尺寸命令、渐变、重置、身高查询           | 已实现                 | 服务端处理有限输入、限幅、权限与持续时间                                                                                                  |
| 瞬时与持续尺寸效果                                  | 主动重设计             | 放大/缩小采用互逆倍率，持续变化使用指数规则，每种两级；主动自用与外部施加分别验证许可                                                     |
| 药水、喷溅/滞留、药水箭                             | 原版投递与独立效果     | 效果入口和持续效果安装有服务端许可保护；全部投递方式的真实双客户端操作仍需手测                                                            |
| 尺寸存取工具                                        | 已实现                 | 抽取/注入受尺寸上下限、稳定状态和共享冷却限制；存量保存在物品组件                                                                         |
| UUID 绑定控制、乘/加/设置/交换/转移                 | 已实现                 | 绑定必须在同维度加载且在有效距离内；双方交换/转移权限先验证，再提交                                                                       |
| 控制器设置界面                                      | 主动重设计             | 使用命令与工具提示，未实现图形设置面板                                                                                                    |
| 射线工具                                            | 主动重设计             | 使用服务端即时射线；没有独立激光投射实体                                                                                                  |
| 工具发射器行为                                      | 未实现                 | 当前不要将储存器、调谐器或光束工具放入发射器并期待专用行为                                                                                |
| 尺寸流体、桶、盆                                    | 部分实现/重设计        | 两类非无限源流体；盆为固定效果块，没有填充、混合和强度系统；玩家环境接触需要 resize 许可                                                  |
| 红石尺寸平台、微型动力输出                          | 已实现                 | 3 模式尺寸场和按尺寸/运动发电，受每 tick 实体查询配额限制                                                                                 |
| 微型装备与升级                                      | 部分实现/重设计        | 普通皮甲、软鞋缓降、背心阻止模组额外植物伤害；没有装备升级/复杂材料属性系统                                                               |
| 滑翔、微型睡眠                                      | 主动重设计             | 手持装具缓降；休息必须使用原版实际床，不支持任意位置露营睡眠                                                                              |
| 食物、随机尺寸                                      | 已实现                 | 独立耗材、管理员食物系数、随机区间/倒计时持久化；自身变化禁用时玩家主动变化停止                                                           |
| 携带、肩/手/自定义位置、骑乘、释放/抛出             | 已实现                 | 一层关系与玩家 opt-in；许可撤回、尺寸比失效、死亡/断连/卸载/传送/重置解除关系；不会从存档恢复旧临时乘客关系                               |
| 携带预设库、隐身/朝向控制                           | 未实现                 | 提供持久偏移与三种位置，没有命名预设或被携带者隐身控制                                                                                    |
| 骑乘能力                                            | 部分实现               | 骷髅射箭、狼冲跃、其他地面坐骑跳跃；没有恶魂火球、爬行者点火等专用能力                                                                    |
| 吹风、压碎、普通跳跃/落地、脚印/生长压力、静止承重  | 已实现/重设计          | 左右脚印随朝向旋转，位移累计步幅；普通跳跃钩子、接地承重；破坏统一配额且默认关闭，不主动生成飞散碎屑实体                                  |
| 动画骨骼碰撞、单脚接触与动态代理 | 未实现，已列计划 | 服务端规范姿态和受预算限制的局部接触，见 [碰撞与物理计划](PHYSICS-PLAN.md) |
| 结构支撑与建筑倒塌                                  | 未实现，已列计划       | 承重为硬度近似；不具备刚体或完整支撑求解                                                                                                  |
| 方块/第三方保护                                     | 已实现基础策略         | 保护 tag、容器、流体、负硬度、世界边界、未加载区块、原版交互保护及 Fabric 方块破坏 veto；未逐项验证所有领地模组                           |
| 全局薄方块形状、微小穿行、水面玩法                  | 未实现专项扩展         | 仅自有盆/平台提供独立形状；不宣称已解决全部微型窒息或原版门/墙交互                                                                        |
| 碎屑食物、投射物/肢体特殊破坏                       | 未实现                 | 不启用旧的大规模实体飞散与专门肢体破坏玩法                                                                                                |
| 按尺寸逃跑与复杂 AI                                 | 未实现                 | 没有自定义尺寸关系逃跑目标；原版与 Rebuilt 既有 AI 行为保持其自身定义                                                                     |
| 观察倍率、精度、平滑与名牌                          | 已实现，世界内验收待补 | 有独立按键；启动检查通过不等于全部巨/微型第一/第三人称视角和 GUI 已实测                                                                   |
| 零/无限浮点尺寸、账户专属行为、其他模组专属表情联动 | 主动移除               | 有限极端尺寸已恢复支持；这些无效尺寸与专属联动仍不属于交付范围                                                                            |

总体状态是有限尺寸玩法实现与明确列出的设计边界，不是所有参考功能的一比一完整移植。尚需双客户端世界内同步/视角操作、完整药水投递/酿造、未实现功能和具体保护模组的进一步验收；不得将这些写成已通过。
